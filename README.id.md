## ✨ Kenapa Loony Terasa Berbeda?

Sebagian besar aplikasi produktivitas terasa seperti PR kantor: puluhan kategori spreadsheet yang rumit, langganan bulanan mahal, dan notifikasi berisik yang bikin cemas.

Loony memilih jalan sebaliknya:

### 🧲 1. Dynamic Island Hidup & Magnetis
Loony tinggal di bagian atas layar komputermu berupa kapsul obsidian yang ringkas. Geser ke mana saja di layar monitor—lepas di dekat tepi, dan kapsul otomatis menempel lembut dengan animasi pegas alami (*spring physics*).

<p align="center">
  <img src="assets/loony-dock.gif" alt="Animasi Kapsul Dynamic Island Loony Menempel Halus di Tepi Layar Windows" width="480" style="border-radius: 10px; box-shadow: 0 6px 20px rgba(0,0,0,0.3);" />
</p>

- **Win32 Click-Through Overlay:** Area transparan di sekeliling kapsul 100% tembus klik. Kamu tetap bisa mengklik tab browser atau teks di editor koding di baliknya tanpa terhalang.
- **Kepribadian Interaktif:** Elus kepala Loony dengan kursor mouse dan lihat matanya tersenyum senang `(^━^)`.
- **Sensitif Terhadap Lingkungan:** Matanya bergoyang halus saat kamu memutar lagu di Spotify atau YouTube, pusing jika digoyang cepat, dan tertidur pulas saat kamu meninggalkan meja kerja.

---

### 🌉 2. Jembatan Instan HP ⇄ Laptop (Instant Bridge)
Sambungkan ponselmu (Android maupun iPhone) ke laptop Windows dalam 3 detik:

<p align="center">
  <img src="assets/mobile-bridge.png" alt="Jembatan Kirim File dan Teks Lokal Wi-Fi HP dan Laptop Tanpa Internet" width="750" style="border-radius: 10px; box-shadow: 0 8px 30px rgba(0,0,0,0.3);" />
</p>

- **Tinggal Pindai QR:** Tanpa registrasi akun, tanpa kata sandi, tanpa verifikasi email. Cukup pindai kode QR di layar dan kedua perangkat langsung terhubung.
- **Papan Klip Bersama (Shared Clipboard):** Salin resi paket, alamat, atau teks di HP—otomatis langsung tersalin di clipboard laptop.
- **Kirim File Tanpa Kuota:** Ambil foto di HP, ketuk kirim, dan file langsung mendarat di folder `Downloads/LoonyBridge` laptop lewat Wi-Fi lokal.
- **Privasi Terkunci (E2EE):** Semua data dienkripsi lokal dengan AES-256 sebelum ditransmisikan. Berkasmu tidak pernah mampir ke server cloud publik pihak ketiga.

### 💰 3. Asisten "Rem Boros" & Catat Cepat Alami
Gak perlu repot buka spreadsheet keuangan yang njelimet. Buka Loony dan ketik hal penting hari ini:

<p align="center">
  <img src="assets/loony-schedule.gif" alt="Pencatatan Cepat Pengeluaran dan Jadwal Alami di Loony" width="600" style="border-radius: 10px; box-shadow: 0 6px 25px rgba(0,0,0,0.3);" />
</p>

- `"Bensin 35rb"` atau `"Kopi 18rb"` ➔ Otomatis memotong jatah harian.
- **Algoritma "Safe-to-Spend":** Menghitung **satu angka aman jajan per hari**. Hari ini boros? Jatah besok otomatis mengerem agar kamu tidak kehabisan uang sebelum tanggal gajian.
- `"Besok jam 14.00 evaluasi tim"` ➔ Masuk ke jadwal agenda lengkap dengan deteksi bentrok otomatis.
- `"Ide: tema terminal retro"` ➔ Disimpan aman di Brankas Ide (*Idea Vault*).

### Kebutuhan Sistem
- **Sistem Operasi:** Windows 10 (64-bit) atau Windows 11.
- **Konsumsi Memori (RAM):** Sangat hemat (~120 MB – 180 MB RAM). Lancar di laptop dengan total RAM 4 GB ke atas.
- **Persyaratan Software:** **Tidak ada.** Kamu *tidak perlu* menginstal Node.js, Python, atau Git.

## 🛠️ Untuk Pengembang & Pembuat Kode

Loony dirakit dengan teknologi web modern yang dibungkus dalam shell desktop native yang sangat ringan:
- **Inti Frontend:** React 19, TypeScript, Tailwind CSS v4, Framer Motion.
- **Desktop Shell:** Electron dengan integrasi sensor Win32 native.
- **Protokol Bridge:** W3C Web Crypto (AES-GCM-256), WebRTC P2P DataChannels, Local HTTP Server.

### Menjalankan dari Kode Sumber (Source Code)
```bash
# 1. Klon repositori
git clone https://github.com/Jipung7/Loony.git
cd Loony

# 2. Pasang dependensi
npm install

# 3. Jalankan mode pengembangan
npm run dev

# 4. Bangun paket installer Windows
npm run dist:win
```
