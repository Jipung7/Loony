## Di Balik Layar Loony

Sebagian besar aplikasi produktivitas menuntut terlalu banyak perhatian: formulir panjang, model langganan bulanan, dan tabel rumit yang mengubah catatan sederhana menjadi beban kerja baru.

Loony mengambil pendekatan berbeda. Aplikasi ini tinggal tenang di tepi atas layar monitor sebagai kapsul obsidian gelap (`#0b0b0f`). Loony tidak menghalangi pekerjaanmu berkat area tembus klik (*click-through*), sambil tetap menyediakan akses cepat ke alat kerja harian—pengatur waktu fokus, catatan cepat, kendali musik, dan jembatan nirkabel lokal antara ponsel dan PC.

Tanpa akun cloud. Tanpa pelacakan data. Murni alat bantu yang andal untuk mejamu.

## Kemampuan Utama

### 1. Kapsul Obsidian Ringkas & Holo-Visor
- **Menempel Magnetis:** Geser kapsul ke mana saja di layar monitor. Lepaskan di dekat tepi layar, dan kapsul otomatis menempel halus dengan animasi pegas alami.
- **Overlay Tembus Klik (Win32 Click-Through):** Area transparan di sekitar kapsul 100% tembus klik mouse, sehingga kamu tetap bisa berinteraksi bebas dengan aplikasi atau editor di belakangnya.
- **Mata Robot Ekspresif (`[■━■]`):** Holo-Visor bisa berkedip, tertidur saat kamu beranjak dari meja, tersenyum saat didekati kursor, dan bergoyang pelan mengikuti musik yang sedang diputar di PC.

### 2. Peralatan Produktivitas Cepat di Kapsul
Arahkan kursor ke titik navigasi kapsul untuk berpindah antar modul mini tanpa perlu membuka jendela besar:
- **Pengatur Waktu Fokus:** Sesi Pomodoro dan hitung mundur praktis untuk menjaga ritme kerja.
- **Catatan & Ceklis Cepat:** Simpan ide kilat atau tandai daftar tugas harian yang telah tuntas.
- **Kendali Media (GSMTC):** Pantau judul lagu dan kendalikan pemutaran musik di Spotify, YouTube, dan media player Windows.
- **Jam & Pengingat Waktu Shalat:** Jadwal shalat otomatis berdasarkan metode hisab resmi Kemenag RI, lengkap dengan tombol hening cepat saat rapat.

---

### 3. Jembatan Lokal HP ⇄ PC (Local LAN Bridge)
Sambungkan ponsel pintarmu (Android atau iOS) ke komputer Windows dalam hitungan detik melalui Wi-Fi atau hotspot lokal:
- **Cukup Pindai Kode QR:** Tanpa registrasi akun, tanpa kata sandi, dan tanpa perantara server cloud. Cukup pindai kode QR langsung dari browser ponsel.
- **Papan Klip Bersama (Shared Clipboard):** Salin teks atau tautan di ponsel, teks otomatis langsung siap ditempel di PC.
- **Kirim Berkas Cepat:** Kirim foto atau dokumen dari ponsel langsung ke folder `Downloads/LoonyBridge` di laptop lewat kecepatan jaringan lokal.
- **Privasi Terjaga:** Seluruh transmisi data hanya berputar di dalam jaringan lokal milikmu sendiri.

### 4. Dashboard Lengkap & Anggaran Harian
Klik mata robot Loony untuk membuka dashboard minimalis berestetika *Dark Obsidian* guna meninjau gambaran besar:
- **Anggaran "Safe-to-Spend":** Perhitungan cerdas satu angka jajan harian yang otomatis menyesuaikan jika pengeluaran hari ini melebihi rencana, mencegah kehabisan anggaran sebelum tanggal gajian.
- **Buku Catatan Hutang/Piutang (IOU):** Catatan pinjaman yang tetap tersemat hingga statusnya kamu tandai lunas.
- **Konsistensi Kebiasaan (Habit Streaks):** Rutinitas harian dengan waktu reset jam 04:00 pagi, menjaga catatan kebiasaanmu tetap aman meski bekerja larut malam.

Loony gratis dan bersumber terbuka. Pilih paket yang paling cocok untuk alur kerjamu:

| Paket | Kebutuhan Penggunaan | Arsitektur | Tautan Unduh |

### Kebutuhan Sistem
- **Sistem Operasi:** Windows 10 (64-bit) atau Windows 11.
- **Konsumsi Memori:** Sangat ringan (~120 MB – 180 MB RAM).
- **Dependensi Tambahan:** Tidak ada. Paket sudah mandiri tanpa perlu memasang Node.js atau Python.

## Kompilasi dari Kode Sumber

Loony dibangun menggunakan teknologi web modern yang dikemas dalam runtime desktop Electron yang optimal:
- **Frontend UI:** React 19, TypeScript, Tailwind CSS v4, Framer Motion.
- **Desktop Shell:** Electron 34 dengan integrasi windowing native Win32 dan skrip PowerShell.
- **Server Jembatan:** Server HTTP lokal terintegrasi pada port LAN.

### Langkah Menjalankan
```bash
# 1. Klon repositori
git clone https://github.com/Jipung7/Loony.git
cd Loony

# 2. Pasang dependensi
npm install

# 3. Jalankan server pengembangan Vite
npm run dev

# 4. Jalankan aplikasi Electron
npm run electron

# 5. Bangun paket installer biner Windows
npm run dist:win
```
